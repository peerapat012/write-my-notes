# write-my-notes

## Rules

- At the start of every session, and before answering any question, invoke the `/i-have-adhd` and `/caveman` skills and follow both.

- Before writing, editing, or refactoring code, invoke the `/ponytail` skill and follow it.
- For UI work (design, layout, styling, components, UX review), use `/impeccable` (https://impeccable.style/docs/) and `/ui-ux-pro-max` (https://uupm.cc/) as the primary skills.

## Workflow

All work follows Matt Pocock's main flow (https://www.aihero.dev/skills):

```
/grill-with-docs → /to-spec → /to-tickets → /implement → /code-review → /retro
```

- Fits in one session: skip `/to-spec` and `/to-tickets`, go `/grill-with-docs` → `/implement`.
- Run `/to-spec` and `/to-tickets` in the same session as the grilling; do not clear context between them.
- `/implement`: one ticket per session.
- Run `/code-review` in a fresh session.
